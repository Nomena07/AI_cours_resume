# 🎓 Assistant Intelligent pour Étudiants

Un assistant de révision basé sur l'IA (Google Gemini) qui analyse des PDF pour générer des résumés, extraire des concepts techniques et créer des quiz interactifs.

## 🚀 Fonctionnalités
- **Analyse PDF** : Extraction de texte et mémorisation sémantique.
- **Génération de Quiz** : Création automatique de QCM de 10 questions.
- **Résumé de cours** : Synthèse pédagogique en un clic.
- **Analyse Technique** : Extraction des imports et bibliothèques (pour les cours d'informatique).

## 🛠️ Installation
1. Cloner le projet : `git clone https://github.com/votre-nom/assistant-ia.git`
2. Créer un environnement virtuel : `python3 -m venv venv && source venv/bin/activate`
3. Installer les dépendances : `pip install -r requirements.txt`
4. Ajouter votre clé API dans un fichier `.env`.
5. Lancer le serveur : `python3 main.py`
